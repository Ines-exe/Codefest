Description
The purpose of this web application is to show users any pantries in Philadelphia that are open at times specified by the user. There are two types of users, those who wish to donate food and those who would like to find pantries. The user can tailor what pantries they find based on distance, hours open and more. With these specifications, the user is able to see a map showing the different pantries they can go to with additional informational. The web application also allows users who which to be donors, add information about any pantries that they chose to open. This information will be saved, and added to the database.
